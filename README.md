# ScheduleSnap
A web application that helps groups find the best time to meet: not just a time that technically works.

[https://schedule-snap.pages.dev/](https://schedule-snap.pages.dev/)

## Key Features

These are what differentiates ScheduleSnap from other scheduling tools:
- **Customizable Preferences**: Instead of binary availability, participants can rank how they feel about each time on a scale.
- **Intelligent Scheduling**: The scheduler uses preferences, participant roles, and other meeting constraints to recommend the fairest, best-fit meeting times.
- **Completely Customizable Availability**: Unlike other scheduling tools that force the organizer to set initial slots for participants to decide between, ScheduleSnap allows participants to completely customize their own availability ranges using a unique calendar-like interface.
- **Easy to Use**: ScheduleSnap is designed to be easy to use and understand.
- **Free and Open-Source**: ScheduleSnap is free and open-source.
- **Accountless**: ScheduleSnap does not require any accounts to use. User authentication data is stored in the browser's local storage, and the system relies on magic links to manage and collect responses.
