FAQ

Quick answers about how ScheduleSnap works, what you need to use it, and how your data is handled.

Getting started

  • Do I need an account?

    No. Organizers create events without signing up. Participants respond via a link — no login required in v1.

  • Is ScheduleSnap free?

    Yes. ScheduleSnap is free to use and open source under the MIT License.

  • What links do I share?

    After creating an event you get a participant link (to respond) and an organizer link (to manage settings and view results). Keep the organizer link private.

  • Can people edit their response?

    Yes, when the organizer allows it. Respondents receive an edit link they can use to update availability and preferences.

How scheduling works

  • What are scheduling windows?

    Broad time ranges when the event could happen — for example, “any weekday next week between 9am and 5pm.” Respondents mark availability inside those windows.

  • How do recommendations work?

    ScheduleSnap scores candidate times using attendance, preference rankings (1–5), and critical attendees. You review ranked suggestions instead of comparing responses manually.

  • What are critical attendees?

    Organizers can mark responses as critical so recommendations only include times when those people are available.

  • How is this different from a poll?

    Polls ask everyone to vote on fixed options. ScheduleSnap lets each person define their own availability and ranks tradeoffs automatically. See the feature comparison.

Privacy & data

  • What data is collected?

    Event details, availability ranges, display names, and optional preference scores. No accounts means no email or password stored for participants.

  • Who can see responses?

    Organizers with the manage link see all responses. Whether participants can view aggregate results depends on event settings.

  • How are links secured?

    Manage and edit links use unguessable tokens. Anyone with the link can access that capability — treat organizer links like passwords.
